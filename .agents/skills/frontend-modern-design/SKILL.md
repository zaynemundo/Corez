# Front-End Modern Design Skill

Use this skill whenever designing or implementing web applications, interfaces, widgets, or components.

## Core Principles

1. **Modern Aesthetic**:
   - Deliver sleek, high-end web designs (dark mode default, curated monochrome and subtle accent colors).
   - Use glassmorphism, subtle borders (`var(--border-color)`), and dark card elevation.
   - Avoid generic browser default styles and plain unstyled elements.

2. **Fluid Typography & Layouts**:
   - Use modern sans-serif font stacks (`Inter`, `-apple-system`, `system-ui`).
   - Standardize typography across text components, headers, inputs, and buttons.
   - Use flexible CSS Grid and Flexbox for responsive, adaptive layouts.

3. **Micro-Interactions & Transitions**:
   - Include hover effects (`transform: translateY(-1px)`), active press states, smooth focus rings, and subtle loading pulses.
   - Ensure high contrast ratios and accessible interactive targets.
