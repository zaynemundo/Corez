# Multi-Agent Engineering Workflow

## Roles and authority

- Codex is the lead engineering agent, owns the implementation strategy, and is the final decision-maker.
- AGY is a subordinate specialist. Codex delegates only bounded tasks with explicit scope and expected output.
- AGY is primarily used for planning, investigation, frontend review, and independent code review.
- AGY recommendations are advisory. Codex reviews them critically and may accept, revise, or reject them.

## Safe delegation rules

- Default every AGY delegation to analysis-only mode (`-Mode Analysis`).
- Use implementation mode (`-Mode Implement`) only after Codex explicitly authorises both the scope and files AGY may change.
- Codex and AGY never edit the same files simultaneously. Codex pauses its edits to delegated files until AGY finishes and the resulting diff is reviewed.
- Never send secrets, credentials, tokens, private keys, `.env` files, environment-file contents, or credential-bearing logs to AGY.
- Never use AGY's `--dangerously-skip-permissions` flag.
- Prefer the repository wrapper, `scripts/agy-delegate.ps1`, so mode, sandboxing, output capture, and failures are handled consistently.

## Review and verification

- Codex inspects every AGY response for unsupported assumptions, scope drift, unsafe advice, and conflicts with repository conventions.
- Codex reviews every file and diff generated by AGY before accepting it.
- After any change, Codex runs all applicable tests, linting, typechecking, and builds. A missing script is reported explicitly; it is never treated as having passed.
- AGY's claim that a change works is not verification. Codex independently reruns the relevant checks and reports the actual results.
- Use `-Mode ReviewDiff` for an analysis-only independent review of the current tracked, unstaged Git diff. The wrapper refuses likely secret-bearing paths.

## Standard sequence

1. Codex defines a bounded task and identifies files that AGY may inspect or, if explicitly authorised, edit.
2. Codex delegates with analysis-only mode unless implementation is necessary and authorised.
3. AGY returns findings or changes; its output is preserved under `artifacts/agy/` by default.
4. Codex critically reviews the response and diff.
5. Codex makes the final engineering decision and performs independent verification.

## Commands

```powershell
# Analysis-only planning or investigation (default mode)
.\scripts\agy-delegate.ps1 -Task 'Inspect the routing design and identify failure modes.'

# Explicitly authorised implementation
.\scripts\agy-delegate.ps1 -Mode Implement -Task 'Modify only src/example.ts to add the validated guard. Do not touch other files.'

# Read-only review of the current tracked, unstaged Git diff
.\scripts\agy-delegate.ps1 -Mode ReviewDiff -Task 'Look for correctness regressions and missing tests.'
```
